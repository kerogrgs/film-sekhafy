# تطبيق "فيلم ثقافي" (Film Sekhafy) ⚽🏆

تطبيق هاتف محمول أوفلاين (Android) مبني باستخدام **Flutter** لتحديات ومسابقات كرة القدم الجماعية بنمط **"تلاتة في واحد" (Three in One)**.

---

## 🌟 مميزات التطبيق

1. **أوفلاين بالكامل (100% Offline)**:
   - يعمل بدون الحاجة لأي اتصال بالإنترنت.
   - بنك أسئلة كروية عربي مدمج ومنظم بترميز UTF-8 لتجنب أي مشاكل في عرض النصوص العربية.

2. **دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL)**:
   - واجهات مخصصة بالكامل بـ `TextDirection.rtl` ومصممة خصيصاً للجمهور العربي والمصري.

3. **طور اللعب "تلاتة في واحد" (Three in One)**:
   - كل سؤال يتطلب ذكر ٣ عناصر كروية (أندية مشتركة، هدافين، أساطير، مدربين، بطولات).
   - زر **"إظهار الإجابة"** لكشف الإجابات النموذجية الثلاثة مع معلومة كروية إضافية.
   - زران واضحان لاحتساب النقاط: **"إجابة صحيحة (+1)"** باللون الأخضر و**"إجابة خاطئة (0)"** باللون الأحمر.

4. **تعدد اللاعبين محلياً (Pass & Play)**:
   - يدعم من **2 إلى 4 لاعبين** على نفس الجهاز.
   - شاشة تمرير الهاتف تضمن عدم رؤية السؤال قبل بدء دور اللاعب.
   - تخصيص أسماء اللاعبين وألقاب كروية عشوائية (الحريف، الساحر، الأسطورة، الكابتن).

5. **شاشة التتويج ولوحة الصدارة**:
   - منصة تتويج تفاعلية (الأول 🥇، الثاني 🥈، الثالث 🥉) مع تأثير احتفالي بالكونفيتي (Confetti).
   - جدول إحصائيات تفصيلي لكل لاعب مع إمكانية إعادة التحدي بنفس الإعدادات.

6. **تصميم رياضي فخم وعصري (Dark & Electric Gold)**:
   - خلفيات ليلية عميقة مع تدرجات ذهبية صفراء مشعة وتأثيرات Glow.

```
│   │   │   ├── app_colors.dart       # لوحة الألوان والتدرجات والتوهج

│   │   └── question_service.dart     # خدمة قراءة وخلط الأسئلة أوفلاين

```

## 🚀 تشغيل التطبيق (How to Run)

لتشغيل التطبيق على محاكي أو جهاز أندرويد حقيقي:

```bash
# تنزيل الحزم
flutter pub get

# تشغيل التطبيق
flutter run
```

لبناء ملف APK جاهز للتثبيت:
```bash
flutter build apk --release
```
